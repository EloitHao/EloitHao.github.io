# 文章

这些文章处于不同的状态。

| 状态    | 含义                                                      |
| --------- | ------------------------------------------------------------ |
| 已完成 | 这篇文章被认为是完成的，但当我想出新的东西时，我可能会编辑它. |
| 写作中   | 这篇文章正在积极编辑中.                          |
| 已暂停    | 该文章被认为是低优先级的。我稍后会回到这篇文章. |
| 已归档  | 这篇文章已经过时了，我可能不会再更新它了. |
